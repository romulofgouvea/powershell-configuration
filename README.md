# Configure PowerShell 7

Instala e configura o profile do PowerShell 7 num passo.

```powershell
git clone https://github.com/romulofgouvea/power-shell-profile.git
cd power-shell-profile
.\Install.ps1
```

Se o `.ps1` for bloqueado:

```powershell
.\install.bat
```

Feche e reabra o PowerShell 7.
